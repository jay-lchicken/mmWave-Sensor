## How it works
1. Upon bootup, users can connect to the sensor via Matter
2. Once linked to matter, users can then see coordinates of presence via Matter. At this point, Bluetooth will be disabled
3. There will be a button on the sensor to enable bluetooth for 10 mins.
4. When Bluetooth is enabled, the users can connect the sensor to the app to draw out zones for the presence detection.

## Main Components Used
1. Hi-Link LD2450
2. Esp32
